# v0.7.1

Fixes handling of alphanumeric SMS sender IDs (e.g. "MY BANK") in the Android app.

## Fixes

- Display and load conversations from alphanumeric senders: encode the address as a URL path segment so spaces round-trip as `%20` instead of `+`, which previously left the conversation empty and showed a `+` in place of the space in the header
- Clear notifications for alphanumeric senders: key them by their normalized text instead of stripped digits, so each sender gets a distinct key and opening a conversation clears the right notification
